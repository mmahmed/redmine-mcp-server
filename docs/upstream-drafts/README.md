# Upstream draft text

Issue and pull request bodies drafted for `jztan/redmine-mcp-server` and not yet filed. Nothing here has been posted, and nothing here is a contribution to the upstream project: these files exist on this fork so the text is not lost between drafting and filing.

Files are named after the backlog item they belong to, in the deployment repository that tracks them.

**Anything security-related is deliberately absent.** Upstream's `SECURITY.md` directs security reports privately to GitHub Security Advisories and asks that no public issue, pull request or discussion be opened for an unpatched report. This fork is public, so a draft describing an unpatched vulnerability does not belong here either — publishing it here would be the disclosure that route exists to avoid.
